# Troubleshooting

<Callout type="info">
Quick triage guide — find the symptom, run the check, apply the fix.
</Callout>

## Fast Triage

<Steps>

### Confirm runtime prerequisites

Verify Java 17+ and `jpackage` are on PATH.

```bash
java -version
jpackage --version
```

### Reproduce with a minimal request

Try a simple request to rule out project-specific issues:

```
GET https://jsonplaceholder.typicode.com/posts/1
```

### Inspect local data

Check `~/.intend/` for file corruption or permission issues.

```bash
ls -la ~/.intend/
```

</Steps>

## Build & Packaging Issues

| Symptom | Cause | Fix |
| --- | --- | --- |
| `jpackage` not found | JDK 17+ not on PATH | Install JDK 17+ and update PATH |
| Windows MSI build fails | WiX Toolset missing | Install WiX Toolset 3.x |
| `InaccessibleObjectException` | Missing JVM flags | `--add-opens` flags are configured in `pom.xml` |
| App icon not showing (macOS) | Icon file missing | Verify `image.icns` exists in project root |

## Runtime Errors

| Symptom | Cause | Fix |
| --- | --- | --- |
| Connection refused | Server down or wrong port | Start target server, verify URL and port |
| Unknown host | DNS typo or no network | Check hostname spelling and connectivity |
| Request timed out | Server unresponsive | Default timeout is 30s — check server health |
| SSL/TLS error | Certificate issue | Verify server cert, check JDK trust store |
| `{{variable}}` not resolved | Variable not captured | Run capture request first, check key spelling |
| History not loading | Corrupted `history.json` | Validate JSON or delete `~/.intend/history.json` |
| Settings not saving | Permission issue | Fix permissions on `~/.intend/` directory |

## Recovery Commands

<Tabs items={["Reset Everything", "Repair History"]}>
<Tabs.Tab>
```bash
rm -rf ~/.intend/
```

Intend recreates defaults on next launch.
</Tabs.Tab>
<Tabs.Tab>
```bash
python3 -m json.tool ~/.intend/history.json
# if invalid:
rm ~/.intend/history.json
```
</Tabs.Tab>
</Tabs>
