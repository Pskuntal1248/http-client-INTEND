# Streaming

<Callout type="info">
Large payload handling stays memory-safe by streaming response bytes directly to disk.
</Callout>

## Trigger Behavior

| Response size | Handling mode |
|---|---|
| Up to 10MB | In-memory response processing |
| Over 10MB | Streaming path suggested/used |

## Streaming Flow

<Steps>
### Execute request

Intend sends request normally.

### Open input stream

Response body is consumed via `BodyHandlers.ofInputStream()`.

### Copy to file

Bytes are piped to disk with `Files.copy()`.

### Return summary

Execution result includes output path and byte count.
</Steps>

## Runtime Settings

| Setting | Value |
|---|---|
| Stream threshold | 10MB (`10 * 1024 * 1024`) |
| Standard timeout | 30s |
| Streaming timeout | 5min |
| Body handler | `BodyHandlers.ofInputStream()` |
| Disk write API | `java.nio.file.Files.copy()` |
