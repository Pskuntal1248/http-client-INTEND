# Getting Started

### Downloading from the Website (Recommended)

1. Navigate to our official website: [intend-1.vercel.app](https://intend-1.vercel.app)
2. Click the **Download** button in the top right corner.
3. Select the appropriate installer for your platform (macOS, Windows, or Linux).
4. Run the downloaded installer.

*Note: We already provide ready-to-use native installers. You only need to build Intend locally from source if you want to contribute to development or perform custom security audits.*

<Callout type="info">
Intend is a native desktop API workspace. You select intent (method, URL, auth, payload) and Intend resolves headers, idempotency, and protocol details automatically.
</Callout>

## 30-Second Quick Start

<Steps>
### Run Intend from source

```bash
git clone https://github.com/pskuntal1248/http-client-intend.git
cd http-client-intend
./mvnw spring-boot:run
```

### Send your first request

- Method: `GET`
- URL: `https://jsonplaceholder.typicode.com/posts/1`
- Click **SEND**

### Inspect what was auto-resolved

Open the **Headers** tab in response details and verify the generated browser-like and protocol headers.
</Steps>

## Native Installers

Download from [GitHub Releases](https://github.com/pskuntal1248/http-client-intend/releases).

| Platform | Package | Install flow |
|---|---|---|
| macOS | `Intend-2.0.0.dmg` | Open DMG, drag app to Applications |
| Windows | `Intend-2.0.0.msi` | Run MSI wizard |
| Ubuntu or Debian | `intend_2.0.0-1_amd64.deb` | `sudo dpkg -i intend_*.deb` |
| Fedora or RHEL | `intend-2.0.0-1.x86_64.rpm` | `sudo rpm -i intend-*.rpm` |

<Callout type="default">
Installers bundle a JDK, so end users do not need a separate Java install.
</Callout>

## Request Examples

<Tabs items={["Simple GET", "POST with auth + variables"]}>
  <Tabs.Tab>

```http
GET https://jsonplaceholder.typicode.com/posts/1
```

Expected summary:

```text
200 Success  |  142 ms  |  1.3 KB
```

  </Tabs.Tab>
  <Tabs.Tab>

```http
POST https://jsonplaceholder.typicode.com/posts
Authorization: Bearer <token>
Content-Type: application/json

{
  "title": "{{randomUser}} post",
  "body": "Created at {{timestamp}}",
  "userId": {{randomInt}}
}
```

Automatically resolved:

| Concern | Intend behavior |
|---|---|
| Payload typing | Detects JSON and sets `Content-Type` |
| Auth | Generates `Authorization` from selected strategy |
| Idempotency | Adds `Idempotency-Key` and `X-Request-ID` |
| Variables | Resolves built-ins and captured values |

  </Tabs.Tab>
</Tabs>
