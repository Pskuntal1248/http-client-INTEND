# Intend

## The intent-driven API client.

<Callout type="info">
**Stop writing headers. Start declaring intent.** Intend is a native desktop HTTP client where you specify *what* you want — method, URL, auth strategy, payload — and the SPI-based header engine resolves *everything* else. No Electron. No account. Fully offline.
</Callout>

Most API tools make you think like a protocol engineer. You paste `Authorization` headers into every request, manually set `Content-Type`, and pray you don't fire a duplicate charge during a retry.

Intend eliminates that entire layer. Select `POST`, pick `Bearer Token` from a dropdown, type your endpoint, write your JSON — hit **Send**. The engine resolves `Content-Type`, `Authorization`, `Idempotency-Key`, `X-Request-ID`, and browser-grade headers automatically. Zero raw headers. Zero guesswork.

## Why Intend

<div className="docs-box-grid docs-box-grid-2">
  <div className="docs-box-card">
    <h3 className="docs-box-title">Zero-Header Requests</h3>
    <div className="docs-box-text">
      You never write <code>Content-Type</code>, <code>Authorization</code>, or <code>User-Agent</code>. The engine resolves every header from your declared intent — method, auth strategy, and payload type.
    </div>
  </div>
  <div className="docs-box-card">
    <h3 className="docs-box-title">Stripe-Style Idempotency</h3>
    <div className="docs-box-text">
      Every <code>POST</code>, <code>PUT</code>, and <code>PATCH</code> gets an <code>Idempotency-Key</code> and <code>X-Request-ID</code> automatically. Retries reuse the same key. New clicks generate new keys. No duplicate charges, ever.
    </div>
  </div>
  <div className="docs-box-card">
    <h3 className="docs-box-title">Pluggable Architecture (SPI)</h3>
    <div className="docs-box-text">
      Headers are resolved through an ordered chain of <code>HeaderProvider</code> plugins. Add custom providers for proprietary auth schemes, signing, or compliance headers — zero changes to core.
    </div>
  </div>
  <div className="docs-box-card">
    <h3 className="docs-box-title">Offline-First, Native Desktop</h3>
    <div className="docs-box-text">
      Built on JavaFX 21 and Spring Boot. No browser runtime, no cloud sync, no account wall. Your data stays in <code>~/.intend/</code> and never leaves your machine.
    </div>
  </div>
</div>
