# Installation

<Callout type="info">
Choose one path: run from source for development, or install a native package for daily use.
</Callout>

## Requirements

| Tool | Minimum | Required for |
|---|---|---|
| JDK (with `jpackage`) | 17+ | Source build and native packaging |
| Maven | 3.8+ | Build (or use bundled wrapper) |
| WiX Toolset (Windows) | 3.x | MSI generation only |

## Install Paths

<Tabs items={["Run from source", "Native installers"]}>
  <Tabs.Tab>

<Steps>
### Clone repository

```bash
git clone https://github.com/pskuntal1248/http-client-intend.git
cd http-client-intend
```

### Start app

```bash
./mvnw spring-boot:run
```

### Optional: build jar

```bash
./mvnw clean package -DskipTests
java -jar target/intend-1.0.0-SNAPSHOT.jar
```
</Steps>

  </Tabs.Tab>
  <Tabs.Tab>

| Platform | Build command | Output package |
|---|---|---|
| macOS | `./mvnw clean package -DskipTests` | `Intend-1.0.0.dmg` |
| Windows | `mvnw.cmd clean package -DskipTests` | `Intend-1.0.0.msi` |
| Ubuntu or Debian | `./mvnw clean package -DskipTests` | `intend_1.0.0-1_amd64.deb` |
| Fedora or RHEL | `./mvnw clean package -DskipTests -Ppackage-linux-rpm` | `intend-1.0.0-1.x86_64.rpm` |

Installation commands:

| OS | Install |
|---|---|
| macOS | Open DMG and drag to Applications |
| Windows | Run MSI wizard |
| Debian family | `sudo dpkg -i intend_*.deb` |
| RHEL family | `sudo rpm -i intend-*.rpm` |

  </Tabs.Tab>
</Tabs>

## CI Build Matrix

Use this workflow to package artifacts for all major desktop targets.

```yaml
jobs:
  package:
    strategy:
      matrix:
        os: [macos-latest, windows-latest, ubuntu-latest]
    runs-on: ${{ matrix.os }}
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-java@v4
        with:
          distribution: temurin
          java-version: 17
      - run: ./mvnw clean package -DskipTests
      - uses: actions/upload-artifact@v4
        with:
          name: installer-${{ matrix.os }}
          path: target/jpackage-input/*
```

## Local Data Layout

```text
~/.intend/
|- history.json             # request history
|- intend-config.json       # dev/prod config
`- intend-state.properties  # idempotency key state
```

<Callout type="warning">
Uninstalling Intend does not remove ~/.intend. Delete it manually if you want a full reset.
</Callout>
