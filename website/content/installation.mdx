# Installation

### Downloading from the Website (Recommended)

1. Navigate to our official website: [intend-1.vercel.app](https://intend-1.vercel.app)
2. Click the **Download** button in the top right corner.
3. Select the appropriate installer for your platform (macOS, Windows, or Linux).
4. Run the downloaded installer.

*Note: We already provide ready-to-use native installers. You only need to build Intend locally from source if you want to contribute to development or perform custom security audits.*

## Requirements

| Tool | Minimum | Required for |
|---|---|---|
| JDK (with `jpackage`) | 17+ | Source build and native packaging |
| Maven | 3.8+ | Build (or use bundled wrapper) |
| WiX Toolset (Windows) | 3.x | MSI generation only |

## Install Paths

<Tabs items={["Run from source", "Native installers"]}>
  <Tabs.Tab>

<Steps>
### Clone repository

```bash
git clone https://github.com/pskuntal1248/http-client-intend.git
cd http-client-intend
```

### Start app

```bash
./mvnw spring-boot:run
```

### Optional: build jar

```bash
./mvnw clean package -DskipTests
java -jar target/intend-2.0.0-SNAPSHOT.jar
```
</Steps>

  </Tabs.Tab>
  <Tabs.Tab>

| Platform | Build command | Output package |
|---|---|---|
| macOS | `./mvnw clean package -DskipTests` | `Intend-2.0.0.dmg` |
| Windows | `mvnw.cmd clean package -DskipTests` | `Intend-2.0.0.msi` |
| Ubuntu or Debian | `./mvnw clean package -DskipTests` | `intend_2.0.0-1_amd64.deb` |
| Fedora or RHEL | `./mvnw clean package -DskipTests -Ppackage-linux-rpm` | `intend-2.0.0-1.x86_64.rpm` |

Installation commands:

| OS | Install |
|---|---|
| macOS | Open DMG and drag to Applications |
| Windows | Run MSI wizard |
| Debian family | `sudo dpkg -i intend_*.deb` |
| RHEL family | `sudo rpm -i intend-*.rpm` |

## CI Build Matrix

Use this workflow to package artifacts for all major desktop targets.

```yaml
jobs:
  package:
    strategy:
      matrix:
        os: [macos-latest, windows-latest, ubuntu-latest]
    runs-on: ${{ matrix.os }}
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-java@v4
        with:
          distribution: temurin
          java-version: 17
      - run: ./mvnw clean package -DskipTests
      - uses: actions/upload-artifact@v4
        with:
          name: installer-${{ matrix.os }}
          path: target/jpackage-input/*
```
