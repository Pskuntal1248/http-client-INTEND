# Sending Requests & File Uploads

Intend natively supports building advanced HTTP requests without requiring you to understand the underlying nuances of `multipart/form-data` encoding or HTTP streaming.

## Working with Text Payloads

The main Body Editor natively supports JSON, XML, and plain text.

As you type, Intend constantly analyzes the shape of your payload:
- If your text starts with `{` or `[`, Intend automatically attaches `Content-Type: application/json`.
- If your text starts with `<`, Intend automatically attaches `Content-Type: application/xml`.
- If it doesn't match these patterns, it attaches `Content-Type: text/plain`.

You never have to define these headers manually.

## Multipart File Uploads

To upload files via `multipart/form-data`:

1. Click the **Attach File** button positioned above the request body editor.
2. Select an image, document, or binary from your filesystem.
3. The body editor will disable text input and display the path to your selected file.
4. If you haven't already, Intend automatically forces the Method to `POST`.
5. Click **SEND**.

Intend calculates the payload boundary and automatically attaches the correct `multipart/form-data; boundary=...` headers.

Click **Clear** at any time to remove the file attachment and return to the standard text body editor.

## Response Streaming

Some endpoints return massive payloads. Intend protects your machine from `OutOfMemoryError` crashes by monitoring the payload size dynamically.

Any response larger than **10 MB** correctly flags the Request Executor to switch into streaming mode. The payload is streamed directly to your disk, ensuring your workspace remains fast and responsive.
